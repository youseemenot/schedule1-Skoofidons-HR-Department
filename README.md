# Skoofidon's HR Department

A MelonLoader mod for **Schedule I** that gives you full control over your workforce. Easily customize employee stats and limits directly from the in-game phone.

## Features
* **Customizable Employee Stats:** Adjust daily wages, signing fees, and walk speeds for Handlers, Chemists, Botanists, Cleaners, and Fixers.
* **Expanded Work Limits:** Override the maximum number of assigned routes, stations, pots, and trash bins.
* **Mod Manager Integration:** Fully compatible with the Phone App for on-the-fly tweaking.
* **UI Improvements:** Automatically adds dynamic scrollbars and fixes UI overlapping on the employee clipboard to accommodate higher assignment limits.

## Requirements
* MelonLoader v0.6.1+ (or v0.7.x)
* Mod Manager & Phone App (by Prowiler)

## Installation
1. Install the required dependencies.
2. Drop `SkoofidonsHRDepartment.dll` into your `Mods` folder.
3. Launch the game and configure your employees via the Phone app!
