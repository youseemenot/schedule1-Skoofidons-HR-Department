# Skoofidon's HR Department 1.1.0

Stable update for **Schedule I 0.4.7f12 IL2CPP**, MelonLoader **0.7.3** and Mod Manager & Phone App **2.2.4**.

## Changes since 1.0.5

- Two consistent performance settings per profession: **Move speed** and **Work speed**. 1 is normal, 7 means seven times faster movement or one seventh of the affected work stage, and 0.5 means half speed.
- Handler: packaging, brick-press preparation and item pickup/placement. Chemist: manual chemistry-station stages, oven pour/harvest, mixer loading and cauldron preparation.
- Botanist: soil, watering, additives, planting, harvest, fungal actions, drying-rack loading and spawn-station work through native employee work speed. Cleaner: litter pickup, grabber emptying, bin bagging and bag pickup/disposal.
- Adaptive clipboard layout for all four professions. Retain the used/limit/free Handler route counter and more than ten displayed station assignments with scrolling/removal.
- Repeated preference saves do not compound the performance factor. Native work effects and product quantities remain in the native pipeline.

Fixed setup/recovery, navigation and mechanical waits retain their existing behavior. For example, dryer unload keeps its 0.5-second animation wait. A whole work cycle can include travel and machine time, so it need not finish seven times faster at factor 7. Automatic cooking, baking, mixing, drying and growth clocks are unchanged. The separate machine-timer block is only an inactive scaffold. Co-op synchronization and property capacities remain deferred.

## Upgrade and installation

1. Close the game. Store prior HR DLLs and `.dll.disabled` backups **outside Mods** to avoid Phone App toggle conflicts. Back up MelonPreferences.cfg before changing settings.
2. Install only `SkoofidonsHRDepartment.dll` into the game's Mods directory. Do not install dependency/reference DLLs or the research BotanistProbe.
3. Start the game and confirm HR **1.1.0** in Latest.log. Configure movement/work multipliers in Phone App and save.

Upgrading from 1.0.5 or the early seconds-based betas: multiplier keys start at 1 instead of reading old absolute WalkSpeed/seconds values. Set desired factors again. Existing beta.3/beta.4 multiplier values retain their keys. Wages/fees remain currency, assignment limits remain counts. There is no separate Botanist enable switch or per-action slider.
