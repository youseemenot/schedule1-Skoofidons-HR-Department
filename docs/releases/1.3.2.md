# Skoofidon's HR Department 1.3.2

HR Department 1.3.2 fixes its F3 settings graphics disappearing after returning to the main menu and loading another world. The embedded menu now retains and restores its generated theme resources across those transitions.

The patch changes shared-menu resource handling. Employee, assignment, production, growth and cost behavior remain as in 1.3.1, including the previous Botanist assignment-limit fix. Existing preferences and HR's Apply changes workflow are preserved.

With [Minimap 2.3.0](https://www.nexusmods.com/schedule1/mods/2343), both mods use one F3 window. Minimap edits apply live; HR edits still need Apply changes. Each mod has its own corrected settings graphics, so update both for the paired fix. HR also works without Minimap, Phone App or a separate shared-menu DLL.

Use Schedule I **0.4.7f12, IL2CPP**, with **MelonLoader 0.7.3**. Close the game and back up `UserData/MelonPreferences.cfg`. Replace `Mods/SkoofidonsHRDepartment.dll`, keep one HR copy in Mods and store backups outside that folder.

The author confirmed that graphics remain stable through repeated world loads with both patched mods; Phone App 2.2.4 was present. Automated checks cover shared-menu sessions, protocol, draft/reset behavior, editors, theme resource lifecycle, current game APIs and stripped Unity compatibility. The recorded checks do not cover every native scenario, language, resolution or mod combination. This release targets singleplayer; co-op configuration synchronization is not implemented.
