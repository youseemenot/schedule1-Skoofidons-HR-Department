# Skoofidon's HR Department 1.3.1

Stable release after the user's confirmation of the Botanist assignment fix. Schedule I **0.4.7f12 IL2CPP**, MelonLoader **0.7.3**; singleplayer.

## Fixes since 1.3.0

- Applying Maximum plants now updates the existing Botanist's live selection limit, alongside the employee limit. An already hired Botanist can use the configured count without re-hiring.
- The existing assignment-row expansion now also supports single selected Botanists, Chemists and Cleaners. Rows follow actual assigned objects, with scrolling and indexed removal; existing assignments are retained when limits decrease.
- The audit confirmed correct live limit application for Chemist Stations, Cleaner Bins and Handler Stations/Routes. Shared F3, settings keys, speed factors and machine timers are preserved.

The user confirmed Botanist assignments above eight, scrolling and removal in 1.3.1-beta.1. All-profession native save/reload and co-op matrices are not claimed. Stable promotion changes only version/startup text; metadata and IL parity with the tested beta are verified. See [acceptance evidence](../testing/2026-11-01-1.3.1-user-result.md) and [assignment audit](../testing/2026-11-01-employee-assignment-limits.md).

## Install and use

Close the game and back up `UserData/MelonPreferences.cfg`. Move previous HR DLLs, including `.dll.disabled` backups, outside Mods. Copy only `SkoofidonsHRDepartment.dll` into Mods, then load singleplayer and press **F3**. Use **Apply changes** after editing. Existing preferences are retained. Reopen the employee clipboard after applying a new limit.

Phone App and Minimap remain optional. English/Russian follows the game's selected language; current-tab reset, shared F3 with supported unchanged Minimap builds, wages/fees and employee/production settings from 1.3.0 remain included.
