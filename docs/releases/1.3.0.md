# Skoofidon's HR Department 1.3.0

Stable settings update for **Schedule I0.4.7f12 IL2CPP** and **MelonLoader0.7.3**, based on user-tested1.3.0-beta.5. Singleplayer. **Mod Manager & Phone App is now optional.**

## Changes since1.2.0

- Open HR settings directly with **F3**. Russian/English follows the game's selected language. Opening the menu frees the cursor and blocks movement/look/world input through the game's UI state; closing returns control.
- Configure employees, hiring, assignment limits and production in one window. **Apply changes** saves HR edits. **Reset to defaults** restores only the selected tab's draft; other tabs are preserved. Closing without applying discards the HR draft.
- Use the same F3 window with supported original **Skoofidon's Minimap2.2.8** or **2.2.8-dev.3**, without updating that DLL. Minimap retains live sliders, toggles, F4 diagnostics and its save delay. Minimap reset asks confirmation for the current tab; Escape cancels confirmation before closing the menu.
- Compatible shared-menu providers register automatically. HR is usable alone, without Minimap, Phone App or a separate shared-menu DLL. The legacy adapter matches exact supported Minimap binaries; unknown old DLLs are left unpatched and may still open their own F3 window.
- Existing employee speeds, machine/growth factors, routes, scrolling and saved preference keys/values are retained. Phone App2.2.4 settings integration remains available when installed.

## Installation and upgrade

1. Close the game and back up `UserData/MelonPreferences.cfg`.
2. Move previous HR DLLs, including `.dll.disabled` backups, **outside Mods**. Copy only `SkoofidonsHRDepartment.dll` into Mods. Keep one HR version; no game/loader/reference DLLs belong in the mod download.
3. Start the game and confirm HR1.3.0 in `MelonLoader/Latest.log`. Load singleplayer and press F3. Existing settings remain; nothing is reset by the upgrade.
4. Optionally leave a supported original Minimap installed; HR connects its settings automatically. Phone App is optional. Existing vanilla/other-mod windows retain their own UI state when HR settings close.

## Performance and limitations

Higher positive speed factors mean faster affected movement/work/progress;0.5means half speed,2twice the rate. Use moderate values. Around7× was useful in the author's testing, not a universal safe limit; extreme factors can cause inefficient movement or unexpected game behavior. This release does not change ranges or add speed caps.

Five machine settings apply to new batches; plant/mushroom factors affect future growth of all growing crops. Native fixed employee pauses and environmental/resource checks remain independent. Co-op synchronization, property capacity changes and exhaustive compatibility with unknown third-party builds remain outside this release.
