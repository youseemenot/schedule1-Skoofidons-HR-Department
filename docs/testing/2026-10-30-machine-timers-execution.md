## Реализация

- Семь default1 настроек в Machine Timers. Коэффициент закрепляется при фактическом создании операции/культуры, сохраняется при изменении предпочтений и входит в дополнительную DynamicSaveData. Текущая неизвестная/legacy операция получает1.
- Целые машинные минуты используют floor+дробный остаток, ограничение оставшейся работой и сброс избытка при завершении. Сушка хранит float-прогресс, рост меняет только положительную будущую дельту в контексте оригинальных callbacks. Вода и работа сотрудников не масштабируются.
- Учтены отдельный минутный callback печи, base-вызов Mk2, захват до вложенного обновления часов, отложенное восстановление посевов и завершённый Load колонии. Save-парсер проверяет GUID, kind/index/fingerprint/progress, версию и диапазоны; invalid/future fallback1.
- Подтверждена текущая игровая цепочка сохранения: Property.GetSaveString → GetObjectSaveDatas → virtual GetSaveData каждого объекта → PropertyData.Objects DynamicSaveData[] → UnityJson. AdditionalDatas сохраняются; PropertyLoader передаёт исходный DynamicSaveData нужному loader. Legacy BuildableItem.GetSaveString не является этой актуальной цепочкой. Runtime roundtrip ещё не выполнялся.
- 45 новых native-целей уникальны среди111сборок/149682методов. Собственный Harmony owner, pinned GameAssembly SHA512, проверка generated binding/pointer и чужих владельцев до регистрации. При ошибке машинный блок снимает свои патчи; штатные employee-функции продолжают работу.
