## Большие множители

Пользователь наблюдал хаотичные/не всегда продуктивные движения Cleaner при значительном увеличении скорости движения и работы. Лог показывает рабочий множитель Cleaner22×, в том числе ожидания0.2→0.009с и0.4→0.018с; Chemistry использовался с99×. По одному логу причина поведения сотрудника не установлена. Пользователь предпочёл описать возможные последствия больших значений, без дополнительного исследования архитектуры игры сейчас.

Рекомендация для описания мода:

> Повышайте множители постепенно, начиная с1×. Уже7× даёт значительное ускорение по опыту автора. Очень большие значения могут приводить к хаотичным движениям, неэффективной работе и другим неожиданным результатам. Более высокая скорость не всегда означает большую производительность. Если поведение ухудшилось, уменьшите соответствующий множитель.

Число7 — эмпирический ориентир пользователя; универсальный безопасный предел не установлен. Программные лимиты, defaults и настройки не меняются.
