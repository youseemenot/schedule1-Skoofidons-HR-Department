# Проверка 1.2.0-beta.2

Локальная сборка для одиночной игры, GitHub stable остаётся1.1.0. Среда: Schedule I0.4.7f12 IL2CPP / MelonLoader0.7.3 / Phone App2.2.4.

## Изменения

Категории: Botanist → Chemist → Cleaner → Handler → Fixer → Machine Timers. Старые ключи и значения сохраняются. Порядок должен быть одинаковым в главном меню и телефоне.

Plant growth и Mushroom growth действуют на **все растущие культуры**, в том числе уже посаженные и загруженные из старого сохранения. После сохранения настроек ближайший штатный расчёт роста использует новое значение. Меняется только будущий прирост: при40% роста изменение множителя не переписывает эти40%. 1 — обычная скорость, 7 — семикратный прирост за тот же игровой интервал, 0.5 — половинный. Вода, освещение, влажность и прочие условия продолжают проверяться игрой. Нет отдельного запоминания коэффициента посева.

Chemistry, Oven, Mixing/Mk2, Cauldron и Drying сохраняют правило **только новые партии**. Изменение настройки не меняет уже захваченный коэффициент партии. Он сохраняется при сохранении/загрузке. Старые партии без метаданных работают с1. Скорость сотрудников и фиксированные паузы независимы.

## Сценарии

1. В логе проверить версию beta.2, HR MACHINE TIMERS READY36 и HR SETTINGS ORDER READY. Проверить порядок категорий в главном меню и телефоне, сохранение прежних значений.
2. С уже растущими растениями и грибами сохранить множитель7. Прогресс сразу не скачет, последующие приросты быстрее. Затем изменить на1 или0.5: тот же посев должен использовать новое значение без пересадки.
3. Загрузить старые культуры при настроенном множителе. Они должны использовать текущее значение. Проверить сохранение/перезагрузку при частичном росте и отсутствие скачка прогресса от самого сохранения.
4. Проверить отсутствие роста при неподходящих штатных условиях; полив и действия работников не должны умножаться повторно.
5. Для каждой машины запустить партию с2, изменить настройку на7: старая сохраняет2, следующая использует7. Проверить ETA, завершение, ресурсы/выход, сохранение/загрузку. На сушилке проверить несколько партий одновременно; на миксерах обе версии.
6. После проверки прислать результат и лог. Не запускать кооператив в рамках этой проверки.
