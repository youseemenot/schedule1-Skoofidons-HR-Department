# Проверка ввода общего меню (временная клавиша F6)

Установлен только SkoofidonsSettingsInputProbe.dll0.1.1. HR1.2.0 и Minimap2.2.8 не заменены; F3/F4 у Minimap сохраняются. Probe не меняет настройки/сохранения/таймеры. Его можно удалить из Mods после закрытия игры.

1. Запустить одиночную игру. Нажать F6 без других меню: курсор свободен, движения мышью не вращают камеру, WASD/прыжок/взаимодействие/использование предмета не действуют на мир. Test click увеличивает счётчик.
2. Закрыть F6, Escape или Close: управление возвращается. Нажать/удерживать W или мышь при закрытии: до отпускания ввода управление не должно возвращаться, после отпускания — возвращается.
3. Открыть игровой телефон, затем F6. Escape закрывает только probe, телефон остаётся и курсор свободен. Повторить поверх паузы. F6 не должен требовать предварительно открывать телефон.
4. Проверить потерю фокуса и повторное открытие; сменить сцену/выйти в главное меню после открытой панели. Никакой невидимой блокировки.
5. Отдельно отметить замеченные реакции мира в кадре открытия/закрытия. При ошибке закрыть игру, приложить Latest.log. Если сбой удерживает ввод, после перезапуска probe не открывается автоматически.

Лог содержит [F3 INPUT PROBE READY/OPEN/SAMPLE/CLOSING/CLOSED] с первыми четырьмя frame-снимками курсора/canLook/canMove. Компиляция/JIT/61API references прошли; это не является доказательством native input изоляции. Лог + результат сценариев нужны для gate этапа1.
