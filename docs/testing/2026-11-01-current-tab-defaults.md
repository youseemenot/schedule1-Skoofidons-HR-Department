# HR1.3.0-beta.4 — стандартные значения текущей вкладки

Пользователь утвердил два графических прототипа и область «Только текущая вкладка». Сборка дополняет HR и встроенный адаптер старого Minimap; оригинальная Minimap2.2.8 /2.2.8-dev.3 остаётся без изменений. Внешний вид: кнопка «По умолчанию» справа в заголовке панели, пояснение области; язык RU/EN по игре.

## Поведение

- HR: восстановление меняет только черновик открытой вкладки. Другие вкладки, включая незавершённый ввод, сохраняются. Пока не нажато «Применить», активные значения и cfg не меняются. Закрытие отменяет этот черновик как раньше. Все31значения берутся из DefaultValue исходных Config entries, включая лимиты/зарплаты/комиссии.
- Minimap через адаптер: кнопка открывает подтверждение для конкретной вкладки. «Отмена»/Escape ничего не сбрасывают; подтверждение немедленно восстанавливает только её исходные prefs, вызывает оригинальный HandleSettingsUpdate и ставит прежнее отложенное сохранение0.5с. DefaultValue берётся из оригинальных23entries, без повторного списка числовых defaults в адаптере.
- Подтверждение закрывает доступ к подлежащим вкладкам/модам/элементам управления. Escape отменяет только его, следующий Escape закрывает F3. F3/потеря фокуса/закрытие сбрасывают незавершённое подтверждение и используют существующее освобождение native lease. Отдельного игрового состояния для диалога не создаётся.
- При ошибке применения Minimap восстанавливаются прежние prefs/cache/pending/due, ошибка остаётся в закрываемом диалоге. Ошибки записи позднее отображаются существующим проверяемым flush. Если выбранная вкладка уже использует defaults, повторной записи не требуется.
- Runtime1.3.0: необязательные BCL hasModal/drawModal/cancelModal callbacks передаются целым набором и обрабатываются на границе provider. Старые панели без этих возможностей остаются совместимыми.

Новый сброс добавлен в панели, поставляемые HR. Современный Minimap2.3.0-beta.2 со своим собственным renderer продолжает работать как прежде; его собственная кнопка сброса потребует будущего обновления того мода. Для текущего сценария с оригинальным2.2.8 это не требуется.

## Проверка в одиночной игре

1. Убедиться в HR1.3.0-beta.4 и прежнем Minimap2.2.8. Открыть F3, HR→Уборщик. Изменить два значения и одно на другой вкладке. Вернуться и нажать «По умолчанию»: восстановлены только параметры уборщика; активные значения сохраняются до Apply.
2. Закрыть без Apply и открыть снова: прежние активные значения на месте. Повторить reset+Apply: defaults сохраняются после открытия и перезапуска. При наличии некорректного ввода другой вкладки сброс не должен его скрыть; Apply по-прежнему проверяет весь черновик.
3. Minimap→Общее: настроить отличающиеся значения на этой вкладке и «Стрелка». Запросить reset и отменить: оба набора остались прежними. Повторить и подтвердить: изменилось только «Общее», ползунки/видимость сразу соответствуют defaults, стрелка сохранена.
4. Повторить сброс отдельно для Маркеров, Положения и Стрелки; для последней ожидаются оригинальные размер1.4 и RGB0/0.8/1. На других вкладках значения сохраняются. Проверить сохранение после перезапуска.
5. В открытом подтверждении попробовать вкладки/сайдбар/фоновые кнопки — они не действуют. Escape отменяет подтверждение, оставляя F3 и свободный курсор; F3 закрывает окно без сброса. Повторить поверх телефона/паузы и при потере фокуса.
6. Проверить маленькое разрешение, RU/EN, обычное закрытие/возврат управления и F4. Прислать Latest.log/замечания.

Политики reset/confirmation/Exit и реальный managed-detour проверяются офлайн; Unity rendering/native controls/file effects требуют игрового прогона. Пользователь ранее сообщил о работе опробованной части beta.3 без нового лога; это не полная матрица beta.4. Stable-теги не меняются, публикация не выполняется.

Финальные результаты: draft8/8, confirmation4/4, session18/18, shared19/19 с frozen fixtures, legacy15/15 на каждой исходной DLL, modern pair18/18; прежние employee/machine/save/layout/optional-phone проверки прошли. Body-audit:192доступных Unity-вызова,0unstripping-заглушек; API397ссылок/13Harmony targets,0ошибок. Независимое ревью не нашло Important/Critical дефектов. Небольшой пробел автоматизации: rollback fixture проверяет prefs и исходно пустой pending; явная проверка всех cache-полей и уже ожидавшего сохранения с ненулевым deadline отложена. Реализация содержит восстановление этих снимков; native-применение при ошибке остаётся в игровой матрице.

Пользовательская ценность выпуска — быстрый возврат после экспериментов с настройками без потери других вкладок. Следующий полезный шаг определяется проверкой и совместимостью; необходимые исправления выпускаются своевременно.
