# Handler 1.0.3: регрессия разметки и лимит станций

Основание: пользовательские снимки 1.0.2 показывают Routes (3/10; free 7), затем (3/21; free 18). Значения реагируют на настройку, но значок Hint перекрывает цифру, а Packaging Station находится далеко ниже Assigned. Пользователь также запросил настраиваемый Assigned (1/3).

Проверка без запуска игры:

- Latest.log загружает ожидаемую 1.0.2 с SHA256 C7BF380034463739F573EBE362F16B3E71F4610C3E83BBD237BDDE633F04B0DD; ошибок HR в исследованном логе нет.
- Исходный PackagerConfigPanel из sharedassets0.assets проверен UnityPy 1.25.4. Stations/Contents имеет anchorTop, pivot (0.5,0.5), высоту 275 и Y=-190. Старый FixListUI делал SetParent(false), сохраняя это смещение, и не менял pivot/позицию содержимого. LayoutElement не решает расположение: дочерние поля панели размещены абсолютными RectTransform.
- RouteListFieldUI/Hint находится в X=105, Y=-19.3 независимо от длины Title. From/To находятся на Y=-55.5. Старый viewport начинался на -35, пересекая область подписей.
- Исправление: Handler через типизированную StationsUI/RoutesUI; viewport станций top=50,height=110, маршрутов top=75,height=160; содержимое привязано к верху viewport с нулевой позицией, ContentSizeFitter. Hint перенесён вправо, заголовок оставляет ему место. Другие профессии сохраняют прежнюю компоновку. Инициализация включает неактивные prefab и BindInternal вновь созданной панели.
- Настройка уже существует: категория Handler Settings, ключ MaxStations, значение 3. ApplyStats менял только Packager.MaxAssignedStations. Теперь обновляется и PackagerConfiguration.Stations.MaxItems для уже созданного поля выбора. Формат данных и ключ настройки сохраняются.
- Новый тест API-границы на реальной DLL: RED 13/14 на 1.0.2 (нет адаптера live-поля). Визуальную регрессию без Unity автоматический тест не воспроизводит; ручные шаги 11–12 добавлены в основной сценарий.

Артефакты исследования находятся вне репозитория: artifacts/hr-ui-investigation/handler-layout.txt и native.txt. Игровые ресурсы в пакет мода не включаются.
