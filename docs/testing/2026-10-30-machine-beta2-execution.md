# Выполнение beta.2

База92908a6 (локальная beta.1), ветка codex/machine-timers. Пользователь после проверки beta.1 согласовал группировку категорий и изменение политики роста. Решение: текущий общий множитель ко всем растущим растениям/грибам, пять машин сохраняют коэффициент новой партии. Сначала пояснять архитектурную рекомендацию и цену альтернатив; правило закреплено в docs/DEVELOPMENT.md.

## Изменения и проверка

- Убраны снимки/захват коэффициентов посевов, сохранения Pot/MushroomBed, их загрузчики и async-маркеры. Остались пять native growth callbacks/setters: меняется только будущий положительный прирост внутри штатного расчёта. ConfiguredRate читается на каждом таком расчёте. Прогресс при загрузке/сборе не масштабируется.
- Упрощены persistence и тесты: пять машин, прежний формат v1, дробный остаток и восстановление сушилок сохранены. Метаданные посевов beta.1 больше не читаются/не создаются.
- Phone App2.2.4 сортирует по Identifier; переименование ключей потребовало бы миграции. Вместо этого три проверенных managed селектора возвращают временный ключ сортировки для шести точных HR категорий. Остальные ключи не изменяются. При несовпадении реализации/чужом патче сортировка отключается отдельно; значения настроек сохраняются.
- RED на прежнем DLL:34/38, ожидаемые отказы порядка/набора targets/новой сигнатуры capture/текущего growth. После сборки38/38. Полный набор176: actualDLL38 + machine29 + saves23 + growth9 + employee12 + Cleaner8 + layout43 + nativeBotanist14.
- Главная сборка без предупреждений/ошибок. API265 внешних ссылок,13 автоматических Harmony targets,0ошибок.36 ручных native targets уникальны по всем111 Cpp2IL assemblies/149682 methods; callbacks разрешены/JIT. Три managed селектора также проверены по сигнатуре и IL.
- Независимое read-only ревью не нашло блокирующих замечаний; повторило saves23 и growth9. Реальная отрисовка и managed detours не доказаны JIT-проверкой, остаются для игры.

Игра агентом не запускалась. Пакет/логи/installation.json находятся вне Git в artifacts/hr-ui-order-1.2.0-beta.2. Перед установкой проверяется отсутствие процесса, сохраняются предыдущий beta.1 DLL и предпочтения за пределами Mods; стабильная1.1.0 уже сохранена. Кооператив и публикация не входят в эту сборку.
