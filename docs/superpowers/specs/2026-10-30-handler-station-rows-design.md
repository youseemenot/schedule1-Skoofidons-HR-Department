# Handler: больше десяти станций

Пользователь запросил назначение более 10 станций и отображение всех назначений в прокручиваемом списке. Использовать существующую настройку Handler Settings / Max Stations; одиночная игра, версия игры 0.4.7f12 IL2CPP.

Подход: расширять Entries типизированного ObjectListFieldUI только для поля PackagerConfiguration.Stations и только по фактическому числу назначений. Клонировать штатную строку с её Title/Icon/Remove, сохранять native Refresh и RemoveEntryClicked(index). Отдельный список или виртуализация не нужны: существующий ScrollRect уже ограничивает область 110 единиц и вычисляет высоту через VerticalLayoutGroup/ContentSizeFitter.

Исходные десять строк сохраняют свою идентичность. Уменьшение Max Stations не удаляет назначения или строки. Невыбранные/чужие поля и multi-selection сохраняют штатное поведение. Новые кнопки не наследуют callback шаблона; после Bind обработчики расширенных строк приводятся к одному вызову с правильным индексом, при последующих Refresh добавляются только новые строки. После изменения списка обновляется layout и ограничивается scroll position; при смене выборки список возвращается к верху.

Выбор реализации — решение исполнителя в рамках прямого запроса пользователя. Ошибка выделения/клонирования не публикует частично расширенный массив и не меняет игровые назначения; созданные строки удаляются, ошибка логируется. Управляемые проверки покрывают расширение/сохранение/откат; рендеринг, назначение 11–15 станций, удаление и reload проверяются в игре.
